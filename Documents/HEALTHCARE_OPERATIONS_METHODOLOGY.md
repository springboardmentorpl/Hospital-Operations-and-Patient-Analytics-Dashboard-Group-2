# MedTrack_DV — Healthcare Operations Methodology

## 1. Introduction

MedTrack_DV is a healthcare operations analytics project developed using data preparation and Tableau visualization.

The project transforms patient and hospital operational data into meaningful analytical dashboards.

The analysis focuses on:

- Hospital performance
- Patient flow
- Department performance
- Resource utilization

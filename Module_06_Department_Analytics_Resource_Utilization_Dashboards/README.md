# Module 06 - Build Department Analytics & Resource Utilization Dashboards

## Overview
This module focuses on developing Department Analytics and Resource Utilization dashboards using the hospital dataset.

## Objectives
- Analyze department-wise performance
- Monitor resource utilization
- Track occupancy and capacity metrics
- Identify operational bottlenecks
- Support data-driven decision making

## Dashboard Components
- Department Performance Analysis
- Resource Utilization Monitoring
- Bed Occupancy Analysis
- Staff and Capacity Insights
- Operational KPI Tracking

## Tools Used
- Power BI
- DAX
- Power Query
- Excel

## Outcome
Interactive dashboards were developed to evaluate departmental efficiency and optimize hospital resource utilization.

# 🏥 MedTrack_DV
## Hospital Operations & Patient Analytics Dashboard

> **Infosys Springboard 7.0 – Data Visualization (Batch 2)**

MedTrack_DV is a Hospital Operations and Patient Analytics project developed to transform hospital data into meaningful KPIs and interactive dashboards.

The project follows a complete data analytics workflow, starting from data generation and cleaning and ending with interactive dashboards, integration and testing.

The dashboards were developed using **both Power BI and Tableau**.

---

## 🎯 Project Objective

The main objective of MedTrack_DV is to provide a simple and visual way to understand hospital operations and patient-related information.

The project focuses on:

- Hospital performance
- Patient admissions and flow
- Department-level analysis
- Resource utilization
- Hospital KPIs
- Interactive data visualization

# Hospital Operations & Patient Analytics Dashboard

## Project Overview

The Hospital Operations & Patient Analytics Dashboard is a data analytics and visualization project designed to analyze hospital operations, patient flow, departmental performance, and healthcare resource utilization.

The project uses Python for data preparation and KPI engineering and Tableau for interactive dashboard development.

## Project Objectives

- Analyze hospital patient and operational data.
- Clean and transform the raw healthcare dataset.
- Calculate important hospital KPIs.
- Develop interactive Tableau dashboards.
- Analyze patient flow and admissions.
- Analyze department and specialty performance.
- Analyze healthcare resource utilization.
- Test and validate the dashboards.
- Document the complete project workflow.

## Dashboard Overview

### Hospital Overview
Provides a high-level view of hospital operations, including cases, admissions, revenue, LOS, and monthly trends.

### Patient Flow
Analyzes patient admissions, case types, severity, LOS, gender distribution, and patient movement patterns.

### Department Analysis
Analyzes specialties, cases, revenue, LOS, CMI, and case-type distribution across departments.

### Resource Utilization
Analyzes doctor status, doctor types, specialty resources, revenue by doctor type, and CMI.
